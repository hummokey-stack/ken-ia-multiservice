# Livrables

Ce dossier contient tous les livrables produits par Jarvis au fil des sessions.

## Structure

```
deliverables/
├── web/          # Sites web, landing pages, composants, code front/back
├── content/      # Textes, scripts vidéo, posts réseaux sociaux, newsletters
├── strategy/     # Plans, roadmaps, analyses, audits, décisions stratégiques
└── automation/   # Scripts d'automatisation, workflows, configs API
```

## Règles

- Chaque livrable est nommé avec la date + sujet : `2026-05-19_nom-du-livrable.md`
- Les fichiers lourds (images, vidéos) vont dans `context/import/` pas ici
- Ce dossier est versionné, ne pas y mettre de secrets ou de clés API
